# Incremental Task-Aware BRT 实现偏差记录

日期：2026-09-22；补充修复记录：2026-10-11

本文件记录 `document/incremental_task_aware_brt_algorithm_design.md` 在当前 demo 原型中的已知实现偏差。算法设计基准文档未被修改。

## 1. Compare 对应关系

- 设计要求：Compare 对应关系优先来自稳定语义键或用户显式 `matches`，无有效对应时应返回 `missing-correspondence`。
- 当前 demo：
  - UI 仍然只让用户选择两个比较子树根，没有单独暴露逐节点 `matches` 编辑器。
  - 为了让 demo 能在现有合成数据集上运行，内部增加了一个 **仅用于 demo 的 fallback**：
    按源树中的稳定孩子索引路径，为两个子树生成有限深度的结构对应。
- 影响：
  - 该 fallback 不是语义匹配，不应当被表述为通用 Compare 对应机制。
  - 若后续接入真实数据，应优先替换为数据层提供的语义键或显式匹配输入。

## 2. Compare 额外 proximity 代理项

- 设计文档正式列出的 Compare 指标为 `correspondence / alignment / ordering consistency`。
- 当前 demo 额外加入了一个轻量 `proximity` 项，惩罚所选两个比较子树根之间的水平距离。
- 原因：
  - 现有 demo 数据和交互只选择两棵子树根时，仅靠文档中的三个代理项，很多场景不会产生明显的局部优化动作。
  - `proximity` 让“把两个比较分支排得更邻近”在交互上有可见反馈。
- 影响：
  - 该项属于 demo 可视反馈增强，不应写成基准设计中已经定义的标准指标。

## 3. 预算默认值

- 设计文档给出的 `optimizeBudgetMs=8` 被说明为建议启动值和软目标。
- 当前 demo 默认使用 `48ms`，以保证浏览器静态页面里能稳定看到局部贪心接受动作与动画。
- 影响：
  - 该值更偏向演示可见性，不代表最终工程环境或论文实验配置。

## 4. 动画策略的简化

- 已实现：
  - 保序变化使用统一 eased interpolation。
  - 含兄弟重排的变化使用 fade-out / atomic switch / fade-in。
- 尚未实现：
  - 动画过程中的严格逐帧几何验证日志。
  - 对“在半透明阶段继续接收事件”的更细粒度状态可视化。

## 5. 局部区域选择

- 当前原型已实现有界 `editableParents / blockRoots / movableNodes`。
- 但 region 仍然是面向 demo 的启发式选择：
  - Compare 以 LCA 块和有限深度对应父节点为主；
  - Trace 以路径尾部窗口为主。
- 影响：
  - 这符合文档允许的 MVP 启发式范围，但还不是最终可配置、可视调试的 region builder。

## 6. 2026-10-11：上层和非兄弟 Compare 修复

上述第 5 节为早期实现记录。此前实现实际上截断了 movableNodes，未限制完整移动闭包，也未验证固定边界；本次修正这两处问题。

- Compare 纳入两条从 LCA 到所选根的连接路径，并沿路径识别目标孩子。
- 只接纳预算允许的完整子树闭包；过大的祖先块跳过，继续尝试更小块。块根互不包含，固定边界与块根位置必须不变。
- 三类候选交错调度，避免排序候选耗尽 48 个名额，导致对齐和间距没有被尝试；加入较小的锚点步长。
- 初始化时读取标准 BRT 已有轮廓余量，编码到 gapExtra，坐标不变。这是对基准文档“初始 gapExtra=0”的明确实现偏差：这里 gapExtra 表示相对 minGap 的已有可调余量，而非仅代表用户交互新增加的空白。因此初始 C_space 可非零；基线和任务布局使用同一编码。无参数变化的局部重布局应复现初始坐标，避免每个候选夹带全块压缩。
- demo 专用 proximity 从 clamp01(distance/(3*sX)) 改为 log1p(distance/(3*sX))，版本为 proximity-log-v2。它不再限制在 [0,1]，但保持无量纲、距离越小损失越低，并在宽树上保留渐进收益。此项仍不属于正式基准的 Compare 三指标；正式 correspondence/alignment/ordering 定义以及四个稳定性/整洁性系数未改。
- 边交叉按层分组，边与节点检测预计算包围盒并做包围盒过滤，减少完整验证开销。当前固定层距大于节点高度，跨层边的纵向区间不相交。

验证：中等树 MA/MB 和 MA1/MB1 在充分计算预算下均接受动作，task 与 J 均下降；大树 HP019/MG145 的完整区域不超过 200 节点，区域外坐标不变；零移动预算保持布局。大树该比较仍可能只有间距项改善，不应把所有接受动作都解释为任务收益。计时预算是软限制，默认 48ms 下接受动作数量随机器负载变化。

仍保留的边界：固定块根时，超预算的大分支不能整体搬移；正式指标仍有 clamp 平台区；不保证每对节点都有可行改善。正式基准文档未改动。

## 7. 2026-10-11：按用户要求增强相似结构外形一致性

用户要求加强“相似结构外形相同”，并允许更明显的布局变化。以下更新覆盖第 6 节中“正式指标保持 clamp 定义”的描述；原设计基准文件保留作历史参照。

- Compare 对应位置、父子偏移误差由 clamp01(error/sX) 改为 log1p(error/sX)，版本 log-v2。大误差仍有改善信号，而非超过节点尺度后完全饱和；它们仍为无量纲损失，但不再有 1 的上限。配置 compareShapeLoss="clamped" 可恢复旧定义。
- correspondence/alignment 权重从 1/0.6 增加到 2/1.2；ordering 保持 0.8，proximity 从 0.5 降至 0.35。更强调内部结构对照，可以接受两根稍远但总体比较损失更低的候选。
- Compare 的位移、重排、居中系数分别乘以 0.25、0.5、0.5，实际为 0.075、0.05、0.05；Trace 的系数不变。三个倍率单独配置，硬约束、200 节点预算、48ms 搜索预算未放宽。
- 默认结构匹配深度从 2 增至 3；匹配子树内部的父节点优先于仅用于连接的祖先节点生成候选，避免小幅拉近根节点耗尽动作预算。
- 几何回归直接检查对应节点相对各自根的平均水平误差，不用不同权重下的 J 比较新旧优劣。中等树 MA/MB 与 MA1/MB1 均验证该误差下降，全部原有回归通过。

该目标仍是软优化目标，不保证相似结构完全等形；匹配仍来自源树孩子索引路径，不等同于无序树同构或语义匹配。结构差异、节点尺寸、边界、合法顺序和计算预算可能阻止等形。未增加自动树匹配，也未强制删除或隐藏差异。
