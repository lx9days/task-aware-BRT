# Task-aware BRT 树布局 Demo

这是一个 D3 + 原生 JavaScript 静态页面，展示同一棵树在不同任务下如何通过排序和对齐策略改变 Buchheim–Reingold–Tilford (BRT) 布局。页面并排显示原始 BRT 与任务感知 BRT；右侧可选数据、任务和目标节点。点击树节点也可选择比较对象或路径终点。

## 任务与策略

| 任务 | 兄弟排序 | 父子对齐 |
| --- | --- | --- |
| Overview / Summarize | 保持原始顺序 | 两端子节点中点 |
| Compare Subtrees | 在被选节点的最近公共祖先处将所属两分支放到相邻位置 | 该祖先与两条比较分支的中点对齐 |
| Trace Path | 每层将目标路径的子节点移向中心 | 路径上的父节点与路径子节点对齐 |

`taskAwareLayout.js` 负责将任务转换为排序与对齐策略，`layout.js` 的 BRT first-walk/apportion/second-walk 是所有任务共享的放置引擎。概览布局也是原始 BRT 的基线。输入树不会因排序被修改。

页面显示宽度、父子中点对称偏差、根下子树规模平衡偏差；比较任务还显示被选子树根的横向距离，以及对应相对深度节点的平均水平位置差；路径任务显示横向偏差与二阶弯曲。指标供视觉验证，不代表已求解加权目标或执行组合优化。比较选择祖先与后代、同一节点时不会形成两个可并排的兄弟分支。

## 运行

通过静态文件服务器提供本目录（ES modules 需要 HTTP，不能直接双击打开 `index.html`）：

```bash
npm run dev
```

在浏览器访问 `http://127.0.0.1:8000`。页面优先用 CDN 加载 D3；如果 CDN 不可达，会使用原生 SVG 绘制备用方案，因此不会出现空白树。根目录相对路径可以用于 GitHub Pages。
