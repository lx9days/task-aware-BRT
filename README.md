# task-aware-BRT

一个基于 `D3.js + JavaScript` 的轻量研究原型，用于比较不同树布局对齐规则在不同任务场景下的视觉效果。

## 在线页面
仓库推送后，可将 GitHub Pages 指向默认分支根目录，页面入口为：

```text
/
  index.html
```

页面使用相对路径加载资源：
- `index.html`
- `style.css`
- `main.js`
- `layout.js`

因此适合直接作为 GitHub Pages 静态页面托管。

## 本地运行
直接用任意静态文件服务打开项目根目录即可。

## 测试

```bash
npm test
```

## 主要内容
- 任务维度拆分为 `低级动作 × 对象`
- 对齐规则包含：
  - `中点对齐`
  - `高权重节点对齐`
  - `大子树节点对齐`
  - `最深子树对齐`
- 内置多组差异明显的树结构测试数据
